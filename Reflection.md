This module has given me a clearer understanding of the interaction between the front-end and back-end components in web applications. Prior to this assignment, I had only used API endpoints; however, for this project I connected those endpoints to a webpage via JavaScript. Using the BREAD methodology to implement the functions within the application assisted me in understanding how the client (browser) can send requests to the FastAPI server and update the webpage in real-time, and therefore eliminate the need to refresh or restart the client's session.

The most difficult component of this project was ensuring all aspects were functioning in harmony. The areas where I experienced difficulties included editing calculations, deletion of records, database errors, and ultimately displaying the appropriate data on the front-end after executing an action. To resolve these challenges, I needed to test individual features, review error messages thoroughly, and make incremental adjustments until all elements functioned correctly. Although it was often frustrating when resolving the many challenges presented by this project, it ultimately provided me with additional experience with troubleshooting both the front-end and back-end code.

I believe another significant portion of this project was using git during development. Creating frequent commits allowed me to monitor my progress and recover from failures. Additionally, utilizing GitHub Actions enabled me to ensure that my project continued to pass all test cases after making modifications to the codebase, providing additional confidence prior to deploying my application.

In conclusion, this module has illustrated how CRUD operations are combined to form a comprehensive web application. Overall, I am confident in my ability to utilize FastAPI, JavaScript, and REST APIs; however, I still desire to enhance my front-end programming abilities as well as increase my efficiency while resolving full-stack application issues.
